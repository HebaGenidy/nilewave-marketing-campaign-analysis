# 📊 NileWave Marketing Campaign Performance Dashboard

## 📌 Project Overview
This project presents an end-to-end performance analysis of **811 digital marketing campaigns** across 6 acquisition channels from **Jan 2024 to Jun 2025**. Built as the final milestone hands-on project for the Excel module at **EraSoft**, this dashboard evaluates revenue efficiency, spending behavior, and audience targeting metrics to drive data-informed marketing decisions.

---

## 🛠️ Tech Stack & Methodology
* **Tool:** Microsoft Excel 2021
* **ETL & Data Cleaning:** **Power Query** (Handled missing data, type casting, and schema normalization).
* **Data Modeling:** **Power Pivot** (Built a star-schema relationship model connecting campaigns, dates, and channels).
* **Calculations:** Advanced **DAX Measures** (Computed dynamic KPIs: ROAS, ROI, CPA, AOV, CVR, and CTR).
* **Visualization & UI Design:** Custom Excel Dashboard with interactive slicers, dynamic cross-filtering, and cohesive visual hierarchy (Hex `#0B2545` color theme).

---

## 🔑 Key Performance Indicators (KPIs)
* **Total Spend:** 17.87M EGP
* **Total Revenue:** 76.12M EGP
* **Total Conversions:** 117,472
* **Overall ROAS:** 4.26x
* **Overall ROI:** 3.26x
* **Average CPA:** 152.11 EGP

---

## 💡 Strategic Data Insights
1. **LinkedIn Efficiency Paradox:** LinkedIn incurred significant ad spend (~4.52M EGP) but delivered the lowest ROI (**1.01x**), indicating a critical need for audience audience refine.
2. **Seasonal Revenue Spikes:** Clear revenue surges occurred during **Ramadan and White Friday** while ad spend remained steady, highlighting strong seasonal organic intent.
3. **Email Marketing ROI:** With minimal budget allocation (~426.69K EGP), Email achieved the highest ROI (**11.55x**), making it a high-potential channel for scaled investment.
4. **Funnel Performance:** Retargeting achieved the highest conversion rate (**39% CVR**) and ROAS (**1125.81**), outperforming initial Awareness campaigns.
